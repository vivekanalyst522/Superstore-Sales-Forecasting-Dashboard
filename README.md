# Superstore-Sales-Forecasting-Dashboard

This project showcases an interactive Power BI dashboard developed to analyze and visualize Super Store sales data. The dashboard provides a comprehensive overview of key business metrics, including Total Sales, Profit, Quantity Sold, and Average Delivery Time. It enables users to monitor performance across different regions, customer segments, product categories, payment modes, and shipping methods.

The dashboard includes dynamic visualizations such as KPI cards, donut charts, bar charts, and year-over-year (YoY) trend analysis for sales and profit. Interactive region filters allow users to explore data for Central, East, South, and West regions, helping identify high-performing areas and business opportunities.

By transforming raw sales data into meaningful insights, this dashboard supports data-driven decision-making and performance monitoring. The project demonstrates skills in data modeling, DAX calculations, dashboard design, and business intelligence reporting using Power BI. It is ideal for understanding sales patterns, customer behavior, and overall business performance through an intuitive and visually appealing interface.
